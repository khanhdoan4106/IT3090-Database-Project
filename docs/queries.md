# Query catalog

The current coursework SQL script includes the following query examples.

## Multi-table queries

1. Passenger name, card ID and card type.
2. Stops on route `T01`, ordered by stop sequence.
3. Active cards that have never been used.
4. Passengers who have used both BUS and METRO.
5. Passengers who have scanned at every station on metro route `M01`.

## Aggregation queries

1. Passenger count by passenger category.
2. Issued-card count by card type, including types with zero cards.
3. Monthly card-use count and total charged amount in 2026, grouped by transport type.
4. Passengers whose October 2026 top-ups total at least 500,000.
5. Route(s) with the highest number of card-use events.

The examples depend on the identifiers and sample business assumptions in the coursework. Verify the test data and expected results before treating them as acceptance tests.
